## IoT Patient Health Monitoring System

This project monitors heart rate and body temperature using sensors
and sends data wirelessly using ESP8266.

### Hardware Used
- Arduino Uno
- ESP8266 (ESP-01)
- Pulse Sensor
- DS18B20 Temperature Sensor
- 16x2 LCD
- Buzzer

### Features
- Real-time BPM monitoring
- Body temperature monitoring
- LCD display
- Wireless IoT data transmission
